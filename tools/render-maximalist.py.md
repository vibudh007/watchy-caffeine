# Instrument artwork

`Face` wraps the 200 × 200 drawing canvas and font placement. The functions in `FACES` draw Signal Box, Patchbay, Pocket Console, Filing Card, and Chart Table. `pack-maximalist.py` reuses the same layouts for the compiled templates. Running this module directly renders design previews with sample values under `build/face-previews/`.

[Template packer](pack-maximalist.py.md), [font notices](../source/watch/ui_font-license.txt).
